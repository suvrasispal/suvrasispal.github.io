Add it to Gmail

      
Web browser, desktop

      
    
        
  1. Click Copy signature above.
    2. 
        
  2. In Gmail, open Settings (gear icon) → See all settings.
    3. 
        
  3. On the General tab, scroll to Signature and click Create new (or select an existing signature to replace).
    4. 
        
  4. Click inside the signature editing box and paste (Ctrl/Cmd + V).
    5. 
        
  5. Under Signature defaults, set it for new emails and replies if you'd like it applied automatically.
    6. 
        
  6. Scroll down and click Save changes.
    7. 
      

    

    

      
Add it to Outlook

      
Desktop app & Outlook on the web

      
    
        
  1. Click Copy signature above.
    2. 
        
  2. Desktop: go to File → Options → Mail → Signatures, choose or create a signature, click inside the box and paste.
    3. 
        
  3. Outlook on the web: go to Settings → Mail → Compose and reply, click inside the signature box and paste.
    4. 
        
  4. Paste with formatting if prompted (Ctrl/Cmd + V, or Keep Source Formatting if offered).
    5. 
        
  5. Set this signature as default for new messages and/or replies.
    6. 
        
  6. Click Save.
    7.
