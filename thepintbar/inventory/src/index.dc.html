Running this at the bar

A browser cannot silently write to a folder on its own. Two honest options, both real:

1 · Linked file (no install). In Chrome or Edge on desktop, use Create & link file or Open local .xlsx above. The browser asks permission once, then every stock movement writes straight into that workbook on disk. Re-grant on each new session.

2 · Local service (fully automatic). Point the data layer at a small Node or Python process on the bar's computer that owns the file — GET /inventory to read, POST /transaction to append and rewrite. The interface already reads and writes through one data layer, so swapping local storage for that endpoint — or for a database later — is a single module change.

Until either is connected, data persists in this browser and exports on demand.
