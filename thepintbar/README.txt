THE PINT BAR — LOGO PACKAGE V1
==============================

Contents
--------
index.html            Presentation page — open in any browser, or deploy the whole folder as-is.
svg/                  9 vector logo files (SVG, single ink).

Files
-----
svg/badge-primary.svg
    Badge — primary — Dark disc, ground artwork. Signage, avatars, stamps.
svg/badge-reversed.svg
    Badge — reversed — Ink on ground. Menus, print, stationery.
svg/badge-accent.svg
    Badge — accent — Red field. One hero application only.
svg/lockup-horizontal.svg
    Horizontal lockup — Website header, email signature, footers.
svg/lockup-horizontal-reversed.svg
    Horizontal — reversed — Dark headers and video lower-thirds.
svg/icon-glass.svg
    Glass icon — App icon, favicon, embroidery, glassware etch.
svg/icon-glass-reversed.svg
    Glass icon — reversed — On ink grounds and photography.
svg/avatar-badge.svg
    Avatar — ringed — Social profile, 40px and up.
svg/avatar-badge-accent.svg
    Avatar — accent — Alternate social profile.

Colours
-------
Ink      #201E1D
Accent   #EC3013 (one hero application per surface)
Ground   #F3F2F2

Type
----
Wordmark    Big Shoulders Display 800/900
Supporting  Archivo 600, tracked wide

IMPORTANT: the SVGs reference these fonts as live text. Convert text to
outlines in Illustrator/Figma/Inkscape before sending artwork to a printer,
signmaker or embroiderer.

Usage
-----
Clear space equals the height of the foam head on all four sides.
Badge minimum size 40px; glass icon holds to 20px.
Do not recolour, stretch, outline or add effects to the artwork.

Deploying
---------
Upload the folder to any static host (Netlify, Vercel, S3, GitHub Pages).
index.html is self-contained apart from the Google Fonts link.
