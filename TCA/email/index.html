How to add this to your email

Click Copy Signature above first, then follow the steps for your email app.

Gmail

  1. Open Gmail → click the gear icon → See all settings.
  2. On the General tab, scroll to Signature.
  3. Click Create new, name it "TCA", then click inside the signature box.
  4. Paste (Ctrl/Cmd+V) — your signature appears fully formatted.
  5. Scroll down and click Save Changes.

Outlook (desktop)

  1. Go to File → Options → Mail → Signatures.
  2. Click New, name it "TCA", then click inside the edit box.
  3. Paste (Ctrl+V) the copied signature.
  4. Set it as default for new messages and replies, then click OK.

Outlook on the web (OWA)

  1. Click the gear icon → View all Outlook settings.
  2. Go to Mail → Compose and reply.
  3. Click inside the signature box and paste (Ctrl/Cmd+V).
  4. Click Save.

Apple Mail

  1. Go to Mail → Settings → Signatures.
  2. Select your account, click + to add a signature.
  3. Click inside the signature box and paste (Cmd+V).
  4. Untick "Always match my default message font" so the styling is kept.
