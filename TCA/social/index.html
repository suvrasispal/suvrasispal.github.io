Social post templates

Four platform-native layouts built from Brand guidelines v1.2. Photography is Unsplash stock pulled from the brand book's own reference set — creative direction only, to be replaced with commissioned photography of real members. All copy is dummy text written to the voice rules.

Editing these in the browser

  1. Text — click any headline, supporting line, badge, stat or button label and type over it. Press Enter in a headline to break the line where you want it.
  2. Photography — use Replace photo, or drag an image file straight onto the template.
  3. Logo — loads from the brand site. If your browser blocks it on export, use Replace logo and pick logo-primary.svg from disk.
  4. Export — Download JPG renders at full export size (not at the size shown here), redrawn from the live text and image.

PSD downloads

The Layered PSD button under each template links to the file by name, so keep the four .psd files in the same folder as this page and the links resolve. Each opens at full export size with the same layer stack: Background, PHOTO — replace, Scrim or Panel, Logo card, a Copy group holding the badge, headline, supporting line and CTA, and a hidden Guides group with the safe margins. Every layer is named with its type token, so the spec travels with the file.

What the browser export does and doesn't do

  • JPG renders at true export size — 1200 × 630, 1080 × 1350, 1200 × 627, 1080 × 1920 — not at the reduced size shown on screen. It redraws from your live text and image rather than screenshotting the page.
  • Guides, keep-out zones and placeholder chips are never included in the export, whether or not they're switched on.
  • Text you type is measured and wrapped in the export the same way the browser wraps it on screen, so a longer headline breaks in the same place. Very long headlines will still overrun the scrim — that's a copy decision, not a bug, and the two-line rule in the book exists for this reason.
  • The logo and stock photos load from other domains. If your browser refuses to export because of that, the JPG button will say so and you can load either from disk with Replace logo or Replace photo.

One limitation in the PSDs, stated plainly

Text in the PSD files is rasterized on named layers, not live Photoshop type — the format's type engine can't be written from outside Photoshop. Layers move, recolour and mask normally, but to change wording either re-set the line with the Type tool using the token in the layer name (Sora 700, Inter 400/600, Space Mono 700, all free on Google Fonts), or just edit and export here.

Before publishing

Replace the stock photography with commissioned images of real members, rewrite the dummy copy against the pillar named in each badge, and write alt text for every image — never left blank. If a photo needs tying to the brand, use one flat tint of Royal Blue or Ink at 15–25% across the whole frame, not a duotone.

One deliberate deviation: pillar badges are set at 16–17px rather than the 11–12px web token. At export scale these assets are viewed at a third to a half size in-feed, where 12px stops being legible and the badge fails the pillar it belongs to.
